# G’s mGBA

mGBAを使用した非公式ブラウザ版GBAエミュレーターです。公開版 net53 をGitHub Pages向けに配置しています。

## 遊び方

GitHub Pagesを有効化した後のURL：
https://kameiktk-svg.github.io/-Gs-mGBA/

1. ブラウザで開き、自分で用意したGBA ROMを選択します。
2. 画面上のボタン、または対応する外部コントローラーで操作します。
3. セーブデータは設定画面から `.sav` として書き出せます。

ROMや利用者のセーブデータは同梱していません。ブラウザ内のデータはURLごとに保存されるため、旧サイトからの移行時は旧サイトでセーブを書き出し、新しいサイトで読み込んでください。

## 主な機能

- GBA ROMの読み込み・記憶、ゲーム内セーブの読み込み／書き出し
- 4つのクイックセーブスロット、バックアップ、倍速・連射
- タッチ操作、外部コントローラー、スキンとボタン配置設定
- 1台での2プレイヤー切り替え、Celio方式のオンライン通信
- 通信エラーログの保存とJSON書き出し

オンライン通信は実験的な機能です。PC版などとの実機通信には未解決のエラーがあり、GitHubへの移設で解消したものではありません。

## GitHub Pagesの設定

このリポジトリの **Settings → Pages → Build and deployment** で、次を選びます。

- Source：**Deploy from a branch**
- Branch：**main**
- Folder：**/docs**

保存後、GitHub Pagesの公開処理が完了すると上記URLから開けます。以降は `main` の `docs/` を更新すると公開内容も更新されます。

友人用のパスワード機能・PKSパッチ機能はこの公開版には含めていません。

### 撮影画質（2026-10-19更新）

スクリーンショットは1440×960のPNG、動画は960×640・最大60fps・映像8Mbps指定です。元のドットを整数倍で拡大し、補間によるぼけを防ぎます。元のゲーム以上の細部を生成するものではありません。動画の実際の品質は端末・ブラウザに依存し、従来よりファイルサイズが増えます。

最新のブラウザ側ソースはこのリポジトリの `docs/` にあります。`docs/source.zip` は公開時点のコア・ビルド資料とブラウザ側ソースのスナップショットです。最新UIの変更を確認する場合は `docs/` を参照してください。


## オフライン対応
初回オンラインで本体・スキンを自動保存します。設定の「オフラインで使う」で「オフライン準備完了」を確認してください。ホーム画面から使う場合は、その画面でも一度オンラインで開いて確認します。ROMは端末内のファイルか記憶ROMを使います。オンライン対戦とソースZIPのダウンロードにはネットが必要です。更新は全画面・タブを閉じて開き直すと適用され、プレイ中の自動再読み込みはしません。キャッシュ削除後はオンラインで再保存してください。

開発時はランタイムファイル変更後に `python3 tools/build-offline.py docs` を必ず実行し、生成された `docs/sw.js` もコミットしてください。


## 操作ガイド
設定 → 情報 → 使い方・操作ガイド。現在のスキン・画面配置を静止プレビューで表示し、説明ボタンで対応位置を強調します。プレビューを押してもゲーム入力は行いません。
オフライン保存時は同じ配信元のリダイレクトを許可し、内容検証は維持します。失敗時のファイル名・HTTP状態・登録エラーを画面に表示します。

### Delta用GBAスキンの読込

設定 → 画面・音量 → 操作・スキン・ボタン配置 →「Deltaスキンの読込」から `.deltaskin` を選択します。PNG/JPEG/PDFの背景・ボタン画像、縦横の配置、GBAボタン、MENU、クイックセーブ／ロード、倍速、撮影を読み込みます。同時押しのA+Bにも対応します。スキンは端末内のIndexedDBに保存し、外部へ送信しません。標準スキンの選択で元の表示へ戻せます。

- GBA用、32MiB以下。画面配置がない従来形式は、縦画面ではコントローラーの上、横画面では中央にゲーム画面を配置します。
- 一方向のみのスキンは、他の向きでも同じ配置を縮小して表示します。
- Delta専用の特殊入力・複数画面・画面フィルターは未対応です。未対応入力は読込後に表示します。拡張タッチ領域とDelta固有のアニメーションは再現しません。
- PDFは読込時に端末内でPNGへ変換します。標準Delta GBAスキンで縦横表示と再起動後の復元を確認しています。

追加使用ライブラリ：
- [fflate 0.8.3](https://github.com/101arrowz/fflate) — MIT、`docs/vendor/fflate-LICENSE`。
- [PDF.js 6.4.299](https://mozilla.github.io/pdf.js/) — Apache-2.0、`docs/vendor/pdfjs/LICENSE`。画像デコーダーのライセンスも同ディレクトリに同梱。
- Deltaスキン形式の参照：[Delta Custom Skins](https://github.com/noah978/Delta-Docs/blob/master/skins/README.md)。スキン自体の著作権・利用条件は各作者に帰属します。

PDF.jsの配布モジュールはgzip分割で同梱し、ブラウザー内で展開して読み込みます。外部CDNには依存しません。

### 画面調整・チート・メモリビューアー

「画面・音量」から自動調整、「チート」からコード登録、「端末」からメモリビューアーを開けます。
画面は表示領域・縦横・安全領域に合わせて調整し、標準表示にも戻せます。
チートはゲーム・プレイヤー別に端末内保存し、各コードをON/OFFできます。PAR v3、GameShark / AR v1・v2、CodeBreaker、VBA直接指定をmGBAの標準処理で読み込みます。マスターコードや複数行コードは同じ登録欄へまとめてください。ゲームの版によって利用できるコードは異なります。通信中はチート適用を停止します。
メモリビューアーは操作中プレイヤーの256バイトを8/16/32bitで読み取り表示します。
最新コアの追加ソース・再ビルド手順は [`tools/core/`](tools/core/) にあります（`source.zip` に重ねて使用）。

設定タブは「画面・音量／ROM／セーブ／通信／端末／チート／外部パッド／情報」の順です。上部右端のROMボタンから読込・記憶設定を開けます。ROMタブ内の再起動・一時停止ボタンは削除し、上部の再起動ボタンは残しています。ブラウザの上下バーで表示領域が狭くなった場合も、ボールスキンの十字キー・A/BとSELECT/STARTが重ならないよう配置します。
